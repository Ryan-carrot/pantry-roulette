# Changelog

All notable changes to Pantry Roulette will be documented here.
Format based on [Keep a Changelog](https://keepachangelog.com).
Versioning follows [Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-04-26 — Initial Release

### Added

- Multi-ingredient search with parallel API queries and deduplication
- 10 vibe profiles with custom keyword scoring engine
- Smart recipe scoring blending ingredient match and vibe alignment
- Diversity filter with localStorage seen recipe tracking
- Full recipe modal with ingredients, measurements, and instructions
- Save to Favourites with localStorage persistence
- Remove from Favourites
- Fully accessible — keyboard navigation, ARIA labels, screen reader tested
- Responsive design from 320px to desktop
- Custom domain at pantryroulette.com
- Open Graph social preview tags
- Google Search Console integration
